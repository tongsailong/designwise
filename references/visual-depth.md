# 视觉深度与跨页视觉语言

> **读这份文档的时机**：阶段 1 写视觉方向、阶段 2–3 做原型与评审、阶段 4 交接 token、阶段 5 实现。
> **一句话立场**：**深度来自层级关系与材质逻辑，不来自渐变与阴影的数量。**
> 本文只展开 `SKILL.md`；原生平台语法见 `native-platform.md`，动效见 `motion-design.md`，素材见 `image-assets.md`。

---

## 1. 视觉深度的四个图层

任何一屏先分层，再谈装饰：

| 层 | 作用 | 手段 | 约束 |
|---|---|---|---|
| **背景层** | 建立空间与氛围 | 低对比底色、极淡纹理/图像、品牌色温 | 不得抢正文；纹理 opacity 通常 ≤8%；大图必须有暗色/降级方案 |
| **表面层** | 组织信息区块 | tonal surface、分组、分隔线、留白 | 同层不叠两层阴影；嵌套不超过两层 |
| **内容层** | 承载信息与主角 | 字体层级、数字、图像、图形 | 一屏一个视觉主角；对比度优先 |
| **前景层** | 操作与浮层 | FAB、sheet、dialog、snackbar、app bar | 阴影只给真正浮起的元素；命中优先级明确 |

**z-order 与对比预算**：越靠前对比越高、越靠后越克制。四层同时“很响”= 没有层级。

## 2. 色彩体系

### 2.1 结构

- **一个温度底色 + 一个主色 + 一个强调色 + 语义灰阶**；数据分类确有 ≥3 维时才增加色相。
- 颜色按**语义**命名（`surface` / `on_surface` / `primary` / `error` …），不按色相命名。
- 主色承担“行动与身份”，不承担大面积背景；大面积用低饱和 surface。
- 强调色只给当前最重要的一件事；同屏多个强调 = 没有强调。

### 2.2 深色模式

- 暗色表面用同色相低明度，不用纯黑；正文不用纯白（用 `on_surface`）。
- 暗色下提高表面层级差（每级约 +4–6% 明度），降低高饱和面积。
- 图片/插画/纹理必须有暗色变体或叠色处理；不简单反相。
- 对比度按暗色实际背景重算，不沿用亮色值。

### 2.3 色彩纪律

| 问题 | 修正 |
|---|---|
| 5 种以上颜色没有主次 | 收敛到 1 主 + 1 强调 + 灰阶 |
| 渐变当“高级感” | 只在有光源/材质理由时用；通常一个线性或径向即可 |
| 低对比“高级灰”正文 | 正文与标签文字 ≥4.5:1；图标/图形 ≥3:1；标签字号 ≥12 |
| 每个状态都用颜色区分 | 先靠文字/图标/位置，再靠颜色；颜色作为辅助 |
| 品牌色铺满背景 | 品牌色回到行动与识别点，背景用中性表面 |

## 3. 材质与光影

### 3.1 材质选择

| 材质 | 适合 | 做法 | 风险 |
|---|---|---|---|
| **纸/哑光** | 阅读、笔记、工具 | 低饱和底色 + 极细噪点 + 轻内阴影 | 噪点过强会脏 |
| **tonal surface** | 大多数 App 区块 | 同色相不同明度，无阴影 | 层级差太小会糊 |
| **玻璃/半透明** | 浮层、导航栏、媒体上覆盖 | 背景模糊 + 半透明 + 1px 高光边 | 低端设备性能；对比度不稳；必须有不透明降级 |
| **金属/硬质** | 专业工具、仪表 | 窄高光 + 明确倒角 + 冷灰 | 容易变成“科技感”套路 |
| **织物/有机** | 生活方式、健康 | 柔和噪点 + 低对比曲线 | 容易软塌、缺少结构 |
| **图像承载** | 首页 hero、空态、叙事 | 真实生成/摄影 + 叠色/遮罩 | 装饰化、抢文字、体积大 |

**规则**：材质服务产品定位；同一 App 的材质语言不超过两种。玻璃只用在一处（如底部导航/浮层），不要全屏玻璃卡。

### 3.2 光影

- **一个主光源方向**（通常左上），所有高光/阴影方向一致。
- 阴影用双层：ambient（大范围低透明）+ key（小范围偏方向）；不要一层大黑阴影糊到底。
- 原生优先用 elevation/tonal surface；CSS 用多层 `box-shadow` 近似，但不要在动画里改阴影。
- 内高光/描边只给需要“浮起”的控件；全屏描边会让界面变脏。
- 光晕/发光只给真正发光对象（状态灯、媒体），不要给按钮和卡片。

### 3.3 空间关系

- 用**重叠、偏移、比例**建立深度：主视觉可略微越出网格，次要元素后退。
- 卡片与背景的明度差是最稳的深度线索；阴影是补充，不是唯一手段。
- 浮层与底层要有明确分离（遮罩、位移、缩放三者至少两项）。
- 滚动时层级变化（app bar 收起、图片视差 2–6dp）可以强化空间，但不能影响阅读。

## 4. 形状、间距与排版

### 4.1 形状

- **圆角按组件尺寸分级**：小控件 4–8，中卡 12–16，大容器 20–28；不要全局一个 24。
- 同一界面混用“全圆胶囊 + 大圆角卡 + 直角分区”会失去秩序；胶囊只给 chip/筛选/短操作。
- 描边/分隔线是最后手段：先靠间距与表面差分组。

### 4.2 间距与节奏

- 4dp 网格；8dp 为主节奏；区块间距 > 组内间距 > 行内间距。
- 留白服务分组与阅读，不服务“看起来很贵”；大留白必须有信息层级理由。
- 首屏密度服务核心任务；详情/专业页可以更密，但分组必须清楚。
- 连续列表用统一行高；穿插大图/大数字会打断扫描。

### 4.3 字体与细节

- 最多 2 个字体族（display + body）；靠字重、字号、颜色建立层级。
- 正文 14–16sp，中文行高 1.5–1.7；标题与正文对比 ≥2.5 倍。
- 数字用等宽/tabular，避免计时与数据跳动。
- 中文标点、避头尾、中西混排空格按 `typography.md`；不要用斜体模拟中文强调。
- 一处“120% 细节”（如精心处理的数字、独特的分隔符、手写标注），其余 80%；不要平均用力。

## 5. 图形、图标与插画体系

| 资产 | 规则 |
|---|---|
| **图标** | 统一线宽/圆角/网格；线性与填充不混用；小尺寸可读；优先矢量 |
| **插画** | 统一色板、线宽、光照、质感、人物比例；同一 App 不超过一种插画语言 |
| **纹理/背景** | 低对比、可平铺/可裁切；不抢文字；提供暗色变体 |
| **空态/引导** | 图必须解释状态或下一步；去掉后信息有损才保留 |
| **庆祝/成就** | 只在真实成果时出现；同一视觉语言，不突然换画风 |
| **照片** | 真实来源、许可清楚、焦点与裁切记录；不用 stock 氛围图凑数 |

**生成素材的一致性**：先定“艺术方向卡”（色板、光照、材质、线宽、构图、禁止项），所有生成图共用；角色/物体需要一致性时先出 master 再作参考图（`image-generation.md` §11.4）。

## 6. 跨页视觉语言（Style Bible）

在 `design-brief.md` 或 `handoff/design-tokens.md` 写一份可执行的视觉 DNA，至少包含：

```markdown
## 视觉 DNA
- 气质：<三个形容词，且能指向产品/用户，不是“高级/简约”>
- 色彩：底色 <hex/语义> / 主色 <hex> / 强调 <hex> / 暗色策略
- 字体：display <族/字重> / body <族/字重> / 数字处理
- 形状：圆角分级 <4/12/20> / 描边策略 / 分隔线
- 表面：主材质 <纸/tonal/玻璃> / 阴影方向与强度 / 纹理
- 图形：图标线宽 / 插画语言 / 图像裁切
- 动效人格：<克制/活泼/精密> / 主缓动 / 转场母题
- 签名细节：<一处>（只一处）
- 禁止：<渐变滥用/emoji 图标/卡片堆/…>
```

**跨页连续性装置**（选 3–5 个，不要每页都换）：
- 统一的页头处理（标题位置、返回样式、动作位置）。
- 同一个强调色只给同类行动。
- 统一的区块标题节奏与间距。
- 同一种转场母题（如列表→详情用共享元素）。
- 同一套插画/纹理语言。

**变化要有理由**：详情页可以更密、阅读页可以更静、庆祝页可以更亮；变化服务任务与叙事，不是每页换模板。

## 7. 反模式（评审直接查）

1. **渐变 + 阴影堆“高级感”**：没有光源逻辑，所有卡片都在发光。
2. **卡片套卡片套卡片**：三层容器，信息被边框切碎。
3. **全局同一圆角**：所有组件 24px，像网页组件库默认值。
4. **玻璃拟态滥用**：全屏半透明卡，对比度不足、低端机掉帧。
5. **纯黑底 + 霓虹色**：赛博套路，阅读疲劳。
6. **图标风格混用**：线性、填充、emoji、3D 同屏。
7. **每页一套插画**：风格不统一，像素材拼贴。
8. **装饰图抢主角**：去掉图信息无损，却占了首屏最大面积。
9. **大留白掩盖信息不足**：一屏只有一句口号，核心任务没有入口。
10. **暗色简单反相**：图片发灰、品牌色刺眼、层级消失。

## 8. 评审与证据

| 检查 | 方法 | 不合格信号 |
|---|---|---|
| 层级 | 眯眼测试 / 灰度截图 | 灰度后主次消失 |
| 结构 | 去掉颜色、阴影、图片，只留灰块与文字 | 核心行为不清楚 |
| 深度 | 看表面层数与阴影方向 | 所有区块同一层；光源方向不一致 |
| 材质 | 同屏材质种类 ≤2 | 纸、玻璃、金属、渐变同时出现 |
| 色彩 | 色相数量与语义角色 | 5+ 色无主次；强调色到处都是 |
| 跨页 | 并排看 3–5 屏 | 页头/间距/强调色/图形语言不一致 |
| 大字体 | 1.0/1.3/1.6/2.0 | 结构靠裁切或缩字号 |
| 深色 | 真实暗色截图 | 纯黑/纯白、图片发灰、对比不足 |

**证据**：并排截图 + 灰度版 + 暗色版；不能只给一屏，也不能用“更精致了”当结论。
