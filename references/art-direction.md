# 艺术指导 · 从产品内容推出视觉，不从风格库挑视觉

> **读这份文档的时机**：阶段 0 写视觉定位、阶段 1 写方向卡与生图 prompt、阶段 2 定 token、
> 阶段 3 判断「技术上都对但就是平庸」到底缺什么。
> **一句话立场**：艺术指导不是选一种好看风格，是**为这个产品的内容找到唯一的视觉论证**——
> 为什么是这个母题、这种材质、这组颜色、这个构图，答案必须来自产品与用户，而不是来自流行趋势或模型口味。
> 本文只展开 `SKILL.md`；视觉 DNA 的字段与跨页装置见 `visual-depth.md` §6，参考拆解见 `design-research.md`。

---

## 1. 艺术指导与相邻概念的分工

| 概念 | 回答什么 | 产物 |
|---|---|---|
| 视觉定位（阶段 0） | 这个产品应该让人**感到**什么，靠什么视觉证据 | `design-brief.md` 的视觉定位段 |
| **艺术指导（本文）** | **为什么**是这套母题/材质/色彩/构图，论证链是什么 | 方向卡的 form 栏 + `direction-approved.md` 的体验基调 + 生图 prompt 的方向块 |
| 视觉 DNA（`visual-depth.md` §6） | 定稿后跨页怎么保持同一套语言 | `handoff/design-tokens.md`、`design-brief.md` |
| 风格库（`design-styles.md`） | 有哪些成熟视觉体系可借用 | 只在论证成立后作为实现参考 |
| 反 AI slop（§5 红线 2） | 排除了哪些廉价套路 | 症状清单，不是风格主张 |

**顺序不可颠倒**：先有论证，再选风格。反过来（先挑风格再编理由）产出的就是「换产品名仍成立」的模板，
概念维直接 ≤5 分。

## 2. 论证链：五步，每步都要能指向内容

```
产品事实（谁、在什么场景、完成什么、系统替他承担什么）
  → 情绪目标（用户在这一刻应该感到：安心 / 掌控 / 被认真对待 / 想继续…）
  → 视觉论点（一句话：用什么视觉证据让人产生这种感受）
  → 母题与形式（从内容对象里抽出的形状/结构/节奏）
  → 具体决定（色彩关系、字体声音、构图、材质光、图形语言）
```

任一步答不出「为什么是它」，就往回退一步，不要用形容词补洞。

**示例（示意，只演示推理形态，不是布局规则）**：
一个「稍后读」工具，产品事实是用户在地铁里用碎片时间读长文 → 情绪目标是「安静、不催我、像纸」→
视觉论点是「界面退成纸的容器，进度是唯一在动的刻度」→ 母题取自书页：页边距不对称、栏宽窄、页码式进度 →
具体决定：暖白低饱和底、正文近黑而非纯黑、无卡片边框靠留白分组、强调色只给「读完/存档」一个动作。
反过来，若答案是「极简 + 大量留白 + 无衬线字体」，它对这个产品和对一个记账 App 同样成立——**那不是艺术指导**。

## 3. 八个必须给出的决定

每个决定都要写成**可检查的一句话**，并落到指定产物；写不出就说明这个方向还没想清楚。

| # | 决定 | 要回答 | 不合格答案 | 落点 |
|---|---|---|---|---|
| 1 | **视觉论点** | 用什么视觉证据，让用户产生哪种具体感受 | 「现代、简洁、高级、有科技感」 | `design-brief.md` 视觉定位 / 方向卡首行 |
| 2 | **母题来源** | 母题取自产品的哪个真实对象/行为/数据形态 | 取自风格库、取自「最近流行的做法」 | 方向卡「form 来自产品的哪里」 |
| 3 | **色彩关系** | 温度、对比结构、面积比、强调色分配给谁 | 「主色蓝 + 辅色橙」却没有角色与占比 | 方向卡 + prompt 方向块 |
| 4 | **字体声音** | 字面密度、行距、数字处理、语气是「工具」还是「读物」 | 「用 Inter，标题加粗」 | prompt 方向块 / `typography.md` |
| 5 | **构图与主角** | 第一眼对象是谁、重量怎么分布、留白承担什么 | 「居中、卡片式、信息清晰」 | 方向卡「主角信息」 |
| 6 | **材质与光** | 表面隐喻来自哪个真实材质场景，光源方向是什么 | 「加一点玻璃拟态显高级」 | `visual-depth.md` §2–3 |
| 7 | **图形与图像语言** | 图标/插画/照片各自承担什么，统一在哪几条规则上 | 「配一些插画增加温度」 | `image-generation.md` §3.6 |
| 8 | **节奏与签名** | 页面之间怎么变化、哪一处是签名细节、禁止什么 | 「每页都精致」 | `visual-depth.md` §6 |

**默认答案测试**（每次写完逐条过）：

1. 这句话换到同类另一个产品上还成立吗？成立 → 不是这个产品的艺术指导。
2. 这个决定能不能被截图检验？不能 → 还是形容词。
3. 去掉它，设计会变差吗？不会 → 它不承担表达，应删。
4. 它是否只是「更贵的默认值」（大留白、大圆角、柔和阴影、无衬线）？是 → 需要给出产品理由或换掉。

## 4. 母题必须从内容长出来

母题的合法性只看一条：**它是不是这个产品内容的结构特征**。

| 内容特征 | 可用的母题方向（示意） | 不可用的做法 |
|---|---|---|
| 数据是连续变化的（步数、心率、预算） | 刻度、进度、区间带、时间轴 | 放一个装饰性圆环，数据与图形无关 |
| 内容是分层的（章节、段落、层级） | 页边、栏宽、缩进、目录装置 | 全部装进等大卡片 |
| 内容是并置比较的（套餐、指标） | 对齐的列、共享基线、差值表达 | 每项一张卡，比较关系被卡片切断 |
| 内容有真实物理对应物（书、票据、地图、乐器） | 该对象的比例、边缘、材质、标记方式 | 用通用几何图形"象征"它 |
| 内容是时间性的（日程、习惯、周期） | 日历网格、节律、间隔 | 用渐变表示"时间流逝" |

**母题不是 logo、不是插画角色、不是装饰图形**；它是反复出现的**结构或比例决定**。
一个方向只能有一个主母题；第二个母题要么是它的变体，要么是干扰。

## 5. 「看起来对但视觉平庸」的四种真实成因

评审遇到「没有明显缺陷，但整屏没有记忆点」时，按这四类定位，不要笼统写「缺少设计感」：

| 成因 | 症状 | 修法（回哪一步） |
|---|---|---|
| **没有视觉论点** | 每页都合理，但说不出这个产品为什么长这样 | 回 §2 重写论点；必要时回阶段 1 换方向 |
| **论点有了，形式没承担** | 说了「安静」，但界面靠装饰和强调色制造热闹 | 回 §3 第 3–6 项，逐项把决定改成可检查的规则 |
| **形式有了，没有主角** | 元素都在，重量平均，眼睛没有落点 | 回构图：定第一眼对象，其余降一档（`critique-guide.md` §构成判据） |
| **局部都对，跨页不成系统** | 单屏好看，连起来像三个 App | 回视觉 DNA 与连续性装置（`visual-depth.md` §6） |

**模型默认口味的识别**：柔和渐变、低饱和莫兰迪、超大圆角、居中大标题 + 副标题 + 两按钮、
无衬线细字重、玻璃浮层——这些不是错，但**没有论证时就是模型口味**。审查看的是「为什么是它」，
不是「像不像高级作品」。

## 6. 与方向卡、prompt、评审的衔接

- **方向卡**：第 2、5 项决定写进「主角信息与素材」「form 来自产品的哪里」；第 3、4、6 项写进方向卡外的一句材质/光影/动效气质。
- **生图 prompt**：八个决定里能被静态图表达的（2、3、4、5、6、7）必须写成具体约束（占比、层级数、光源方向、材质种类、禁止项），不只写风格形容词。艺术方向卡的完整字段见 `image-generation.md` §3.6。
- **设计决策**：`direction-approved.md` 记录被采用方向的论点与八个决定，融合时写清哪些决定被保留、哪些被替换、为什么。
- **阶段 3 评审**：不新增评分维度。用本文件第 5 节定位「平庸」的成因，用 `critique-guide.md` 的构成判据给位置与改法；**「不够高级」不是缺陷，「论点未被执行」才是**。

## 7. 常见失败

| 失败 | 症状 | 修正 |
|---|---|---|
| 用形容词代替论点 | 「温暖、克制、有质感」 | 改成「暖白纸面 + 单一进度刻度 + 无边框分组」 |
| 母题来自风格库 | 因为最近流行就上手 | 回到内容结构找一个真实对象 |
| 一个方向塞三个母题 | 圆环 + 波浪 + 网格同屏 | 只留主母题，其余删除或降为背景 |
| 论证只在文档里 | prompt 与 token 完全没体现 | 把决定写进 prompt 方向块与 token 命名 |
| 为了「有记忆点」硬造符号 | 生造一个与产品无关的图形 | 记忆点应来自内容的结构特征 |
| 把反 slop 当风格 | 刻意不用渐变/圆角，结果像未完成 | 反 slop 是排除项，不是主张；先有论点 |
