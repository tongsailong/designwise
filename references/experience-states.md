# 完整体验状态 · 从静态页面到状态机

> **读这份文档的时机**：阶段 0 建状态地图、阶段 2 做原型、阶段 3 评审、阶段 4 交接、阶段 6 验收。
> **一句话立场**：**用户看到的不是页面，是页面在某个状态下的样子。** 只设计正常态，等于只设计了产品的一小部分。
> 本文只展开 `SKILL.md`；id 与覆盖以 `state-map.md` 为准，动效规格以 `motion-design.md` 为准，平台行为以 `native-platform.md` 为准。

---

## 1. 状态的三层

| 层 | 回答 | 例 |
|---|---|---|
| **数据状态** | 内容处在什么阶段 | 加载 / 有数据 / 空 / 部分 / 错误 / 离线 / 权限 / 锁定 / 额度用尽 |
| **交互状态** | 控件当前可做什么 | 默认 / 按下 / 选中 / 聚焦 / 禁用 / 拖拽 / 提交中 |
| **转场与结果状态** | 正在发生什么、结果如何 | 进入 / 离开 / 共享元素飞行中 / 成功 / 失败 / 可撤销 / 完成 |

**状态地图只写数据状态是不够的**：`P*`/`S*`/`X*` 的“状态集合”至少要覆盖数据状态；交互与转场在原型说明的动效矩阵中补充（`motion-design.md` §6）。

---

## 2. 数据状态设计表

| 状态 | 界面必须给出 | 主操作 | 动效 | 禁止 |
|---|---|---|---|---|
| **首次加载** | 结构占位（骨架）或明确进度 | 取消（若 >1s） | M06；>300ms 才出现 | 白屏、永久 spinner |
| **刷新** | 保留旧内容 + 刷新指示 | 继续浏览 | 下拉/顶部指示 | 清空旧内容导致跳动 |
| **有数据** | 真实内容、层级、时间/来源 | 核心任务 | M07 一次性入场 | 每次滚动重播 |
| **空（首次）** | 解释这是什么 + 一个开始动作 | 添加/创建 | 轻量插画/图标 + M07 | “暂无数据”四个字 |
| **空（已清空）** | 肯定完成 + 下一步 | 返回/再添加 | 轻量确认 | 与首次空态同一文案 |
| **空（无结果）** | 说明筛选条件 + 清除/放宽 | 清除筛选 | 直接替换 | 假装是首次空态 |
| **部分成功** | 哪些成功、哪些失败 | 重试失败项 | 行内标记 | 整页报错吞掉成功结果 |
| **错误（可恢复）** | 发生了什么 + 为什么 + 重试 | 重试/返回 | M09 | 只说“失败”、无出口 |
| **错误（不可恢复）** | 原因 + 替代路径/联系 | 返回/反馈 | 静态 | 死循环重试 |
| **离线** | 离线标识 + 可用内容 | 重连/查看缓存 | 顶部 banner | 把缓存当实时数据 |
| **数据过期** | 最后更新时间 + 刷新 | 刷新 | 轻提示 | 静默展示旧数据 |
| **权限未授权** | 为什么需要 + 授权入口 | 授权/稍后 | 轻提示 | 一进来就弹 |
| **永久拒绝** | 去系统设置的具体路径 | 打开设置 | 静态 | 反复弹窗 |
| **锁定/未解锁** | 条件 + 当前进度 + 解锁动作 | 去完成条件 | M25（仅真实机制） | 假进度、诱导付费 |
| **额度用尽** | 用量 + 恢复时间/方式 | 等待/升级（若真实） | 静态 | 虚假稀缺/倒计时压迫 |
| **待解析/处理中** | 真实阶段 + 预计 | 取消/等待 | 进度 | 用假标题/假进度顶替 |
| **完成终态** | 成果 + 下一步 | 继续/返回 | M24 一次 | 无限庆祝、阻塞操作 |

**文案要求**：说清“发生了什么、为什么、下一步”；不指责用户；不编造数字；演示数据必须标注。

## 3. 加载策略（避免闪烁与假等待）

| 预计耗时 | 策略 |
|---|---|
| <300ms | 不显示 spinner（避免闪一下）；直接出内容 |
| 300ms–1s | 骨架屏，保持布局结构；数据到达原位替换 |
| 1–10s | 明确进度/阶段文案 + 可取消；保留导航 |
| >10s | 转后台 + 通知/角标；允许离开页面 |
| 失败 | 保留已有内容；给出重试；不自动无限重试 |

**骨架屏规则**：形状与真实内容一致；不做夸张 shimmer；减少动态下静态占位；骨架不阻塞滚动。

## 4. 交互状态

| 状态 | 必须可感知 | 实现 |
|---|---|---|
| 默认 | 可点性明确 | 形状/颜色/文案 |
| 按下 | 手指下立即反馈 | 状态层/涟漪/缩放（M01） |
| 选中 | 与未选中可区分 | 指示器/着色/勾选（M02） |
| 聚焦 | 键盘/辅助技术位置 | 焦点描边；不被颜色单独承担 |
| 禁用 | 不可点且原因可查 | 降对比 + 说明；不用纯灰无解释 |
| 提交中 | 防重复提交 | 按钮进入 loading；保留结果路径 |
| 拖拽/滑动 | 跟手与阈值 | 手势动效（M27）；松手 spring |
| 长按 | 有次要操作时 | 菜单/预览；不隐藏核心操作 |

**禁止死控件**：只画外观、点不动、点了没结果、返回不可达 —— 属致命缺陷（`SKILL.md` §2.2 阶段 3）。

## 5. 转场状态

| 转场 | 要求 |
|---|---|
| 进入页面 | 方向性位移；共享元素连续；返回保持滚动位置 |
| 离开页面 | 反向；未保存内容要确认或自动保存 |
| 弹层打开 | 遮罩 + 面板；背景不可误触；返回先关弹层 |
| 弹层关闭 | 按钮/下滑/返回至少一种在最大字号下可达 |
| Tab 切换 | 各 tab 保留栈；指示器跟手；不重建整个页面 |
| 数据更新 | 插入/删除/替换有动画但不阻塞滚动 |
| 中断 | 转场中返回、连点、切 tab：以最后一次为准，不叠加 |
| 失败回退 | 乐观更新失败要回滚并提示；不留下假成功 |

## 6. 结果与反馈

| 反馈 | 时机 | 形式 | 要求 |
|---|---|---|---|
| 即时 | 按下/选择 | 状态层/勾选 | ≤100ms |
| 短时 | 保存/复制/删除 | Snackbar / toast | 可撤销；不遮挡主操作 |
| 行内 | 表单校验 | 字段下文案 + 描边 | 说明具体原因 |
| 持久 | 离线/权限/额度 | Banner / 状态区 | 可关闭或可恢复 |
| 庆祝 | 真实成果/解锁 | M24/M25 | 一次、可跳过、不阻塞 |
| 触感 | 确认/选择/失败 | haptic | 不每次点击都震 |

**反馈不等于庆祝**：保存成功一个 snackbar 就够；不要每次操作都全屏动画 + 震动 + 音效。

## 7. 跨页叙事

一个完整体验至少有五个节拍：

1. **进入**：我在哪、现在最重要的事是什么。
2. **行动**：核心操作清楚、可达、有反馈。
3. **等待**：加载/处理有真实阶段，不假装即时。
4. **结果**：成功/失败都有解释与下一步。
5. **收束**：完成态给成果与去向，不突然断掉。

**跨页连续性**：同一任务跨页时保留上下文（选中的文章、筛选条件、滚动位置）；返回不丢状态；完成一个任务后给出自然的下一步，而不是回到空白首页。

**节奏**：不是每页都要高潮。工具页克制、结果页确认、里程碑页才庆祝；一个流程最多一个“高光时刻”。

## 8. 原型与覆盖

- 每个状态要么可到达（真实路径/查询参数），要么 `deferred-native` + 理由 + `native_verify: true`（`state-map.md` §6）。
- 状态切换只改数据与状态，不改布局骨架；否则评审无法判断是状态还是另一版设计。
- 评审用状态切换器时必须标注“非产品 UI”，不进 baselines，不替代真实路径。
- `coverage.json` 继续使用 `kind=page|overlay|state`；转场与交互动效不新增 id，写入 `prototype-notes.md` 的动效矩阵与 `handoff/states-interactions.md`。

## 9. 交接与验收

`handoff/states-interactions.md` 至少包含：

| 内容 | 要求 |
|---|---|
| 状态矩阵 | `P*`/`S*`/`X*` × 数据状态；每项文案、主操作、视觉、动效 id |
| 交互状态 | 按下/选中/禁用/提交中/长按的行为与视觉 |
| 转场规格 | 进入/离开/弹层/tab；时长、缓动、中断、降级 |
| 反馈规格 | snackbar/banner/haptic/庆祝的触发与文案 |
| 恢复路径 | 错误/离线/权限/额度/锁定的出口 |
| 平台差异 | 系统返回、insets、键盘、深色、字体缩放 |
| 证据 | baselines 命名对齐；动效录屏/帧 |

**验收时按 `SKILL.md` §2.2 阶段 6 已定义的体验维度核对**；本文只给判据，不新增验收维度、不改矩阵口径：

| 维度 | 判据 |
|---|---|
| 状态转场与恢复 | 进入/离开/弹层/返回/中断可完成；失败可回滚；无假成功 |
| 动效与反馈 | 每个关键交互有反馈；转场方向正确；减少动态生效；无动画锁输入 |
| 体验叙事 | 跨页上下文保留；完成态有下一步；庆祝只对真实成果 |

---

## 10. 反模式

1. 空态只写“暂无数据”，没有解释与下一步。
2. 加载永远转圈，没有阶段、没有取消、没有失败。
3. 错误只说“操作失败”，没有原因与重试。
4. 每个操作都弹 toast，打断阅读。
5. 每次保存都全屏庆祝，反馈通胀。
6. 乐观更新失败不回滚，留下假成功。
7. 返回后筛选/滚动/输入丢失。
8. 状态切换改布局骨架，评审无法比较。
9. 用“演示数据”掩盖真实业务规则缺失。
10. 庆祝/成长动画绑定了并不存在的机制（为动效新增积分/任务/徽章）。
