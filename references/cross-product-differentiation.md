# 跨产品差异化 · 六项检查

> **读这份文档的时机**：同开发者或同品类已有另一个产品；用户说「看着像同一个」「缺少辨识度」；
> 一批素材定稿前；接手别人做过的品牌要续做。
> **一句话立场**：差异化不是「换点东西」，是**两个产品的视觉身份在结构层真的不同**，而不是同一套
> 语法换了两套词汇。检查的目的是**解释相似落在哪个维度**，不是给一个相似度分数。
> 本文只展开 `SKILL.md` §6.5；身份层的推导见 `visual-identity.md`。

---

## 0. 何时查（不查也是正常结果）

满足任一条件才查；**其余任务不查**，不为流程完整强行对比：

| 触发 | 例子 |
|---|---|
| 与同开发者/同品类另一产品有**实际混淆风险** | 同一账号下的两个 App、同一商店同类目 |
| 用户或评审报告了「像同一个产品」 | 本次任务的起因 |
| 同一轮里为**两个以上**产品做设计 | 同时出两套市场图 |
| 产品自有语言与另一产品**已经重叠** | 同材质家族、同底色温度、同构图语汇 |
| **连续两批**素材只能靠同一套版式成立 | Campaign 已退化为模板（见 `visual-identity.md` §5） |

---

## 1. 换名测试（最硬的一条）

**做法**：把产品名、Logo、以及能唯一指向产品的文案全部遮住，只看视觉。给一个不知道背景的人看，
问一句：「这两张是同一个产品吗？」或「这是一家的两个产品，还是两家公司的产品？」

**判定**：
- 遮住名字后**仍能说出两个不同的视觉身份**（不同的主角、不同的构图、不同的图形语言）→ 通过。
- 遮住名字后像**同一品牌的两次 Campaign** → 不通过。这正是本案：两套素材只差字体与色相。

**不得用模型自评代替**：模型看图会说「都很好」。这条测试要的是「去掉标识后还剩什么」，
用本机真实图片给人看，或者按 §5 的维度表逐项比对，**不把某次模型评分当作用户辨识度实验**。

---

## 2. 母题测试

**做法**：去掉全部文字，只留视觉主体。问三句：
1. 这个画面是否表达了这个产品的核心价值（不是装饰）？
2. 把母题换成另一个产品的母题，画面会变得更差吗？如果不会，它就不承担识别任务。
3. 母题是从产品内容长出来的，还是从风格库挑的？

**判定**：母题是「漂亮装饰」而非「识别装置」→ 不通过。记录时写清母题来源（哪个真实对象/行为/
数据形态），写不出就说明它只是装饰。

---

## 3. 构图测试

逐项比较，**用数字不用感觉**（`scripts/check-visual-identity.py` 会给这些事实）：

| 项 | 怎么读 |
|---|---|
| 主视觉（截图/插画/图形）占画面面积 | 两产品是否落在同一区间 |
| 视觉重心位置 | 上/中/下、左/右；是否都在同一处 |
| 文字区占画面上部比例 | 本案 40.6% vs 28.1%，是真实差异 |
| 留白策略 | 边距制度是否同一套（本案 92 vs 96px，实质相同） |
| 页面节奏 | 五行文字的密度与行距是否同构 |
| 视觉引导路径 | 第一眼 → 第二眼 → 行动的顺序是否相同 |

**判定**：**主视觉占比、重心、文字区比例、引导路径**里若有三项以上落在同一区间，判结构同构。
只换颜色、只换字体、只加装饰**都不改变**这四项。

---

## 4. 视觉语言测试

比较六件东西，逐件问「这是不是同一套语言」：字体系统（不只是字面，还有字阶比与数字处理）、
材质与光影（光源方向、纹理尺度、表面隐喻）、插画/图像策略、图形语言（线宽、圆角、标记法）、
色彩逻辑（角色与面积比，不只是色值）、装饰语汇（分隔线、方标、印章、页码这类小装置）。

**判定**：六件里有四件以上同构 → 不通过。**注意**：色彩逻辑同构不等于色值相同——本案赤陶
`(168,64,42)` 与朱红 `#B00000` 色相不同，但「只出现在眉标/序号/判断词上、占画面 <5%」这个
**角色与面积分配**完全一致，所以算同构。

---

## 5. 参考污染测试

**做法**：翻本次任务真实留下的材料，逐项确认——
- prompt 有没有抄另一个项目的方向块或材质描述？
- 参考图是不是另一个项目用过的？
- Recall / 记忆有没有召回另一个产品的视觉规则？
- 素材目录里有没有混入另一个项目的成品或中间产物？

**判定**：有跨项目材料进入且**未说明借用维度** → 不通过。修法是写明借用的是哪一维（例如
「只借纸纹的尺度，不借它的版式」）或换掉。

**如实记录零命中**：本案两项目的文档、prompt、素材互不引用，污染测试**零命中**。查不到就写查
不到，不要为了凑一条结论编造污染证据。

---

## 6. 产品内一致性测试（与差异化同时成立）

差异化**不能**用「每张都不一样」来实现。同一个产品的多张素材必须能看出同源。

**做法**：把同产品的一批素材并排缩小到商店货架宽度，问：这五张是一个产品吗？再看它们**是否
只是同一版式复制五遍**（若只有文案与截图不同，说明停止设计了，见 `visual-identity.md` §5）。

**判定**：两件事都要成立——**能认出同源**，且**不是同构复制**。

---

## 7. 归因表：相似落在哪一层，决定改什么

| 相似所在层 | 是否缺陷 | 处置 |
|---|---|---|
| 母题、第一视觉对象、构图比例、图像策略、视觉隐喻 | **是** | 改结构；回身份层重推母题或换主角 |
| 字体系统、材质与光影、图形语言、装饰语汇 | **是** | 换语言，不是换字面；材质与图形要落到可检查规则 |
| 色彩**角色与面积比** | **是** | 改角色分配（谁承担强调、占多少面积），不是换一个相近的色相 |
| 仅色值相近但角色不同 | 视情况 | 若结构已实质不同，可不改；反之改了也没用 |
| 画布尺寸、真实截图、一图一卖点、缩略图可读、平台惯例 | **否** | 不要改。这是合理共性 |
| 同一产品内部的一致性 | **否** | 这是优点，不是同质化 |

**不为差异化而差异化**：为了通过检查去换色、加装饰、改栏数、故意做丑，是拿指标替代产品判断。
差异必须由**身份层的不变量**解释：说出「因为这个产品的第 X 条不变量，所以这里是 Y」，
说不出来就不要改。

## 8. 工具：只给事实，不裁决

```bash
# 描述两个（或多个）真实成品的 frame 事实并逐维度对比；不输出通过/不通过
python3 scripts/check-visual-identity.py \
  --image pedometer/01-final.jpg --label 计步器 \
  --image rili/01-today.png --label 历法

# 记进本机外观指纹（只存事实与 sha256，不存图片），供下次跨项目对比
python3 scripts/check-visual-identity.py --image x.png --label rili --record
```

输出的每一项都是**可核对的事实**：底色与主色角色、边距、文字区比例、主视觉占比与位置、字阶比、
分隔线数、装饰位。判定由人（或按 §7 归因表逐项）做。

**边界（硬约束）**：
- 脚本**不给 verdict、不改退出码**；没有「相似度超过 X 就算同质化」这种阈值。
- **不得**用图片相似度、颜色比例或模型评分**裁决**设计质量。
- 既有 `scripts/direction_divergence.py` 的 `skeleton_correlation` **只用于同产品内多方向比较**。
  实测（2026-11-25，两个真实产品各 5 张成品）：对本案给出 `skeleton_correlation=0.2138`
  判为「不同骨架」——**假阴性**，因为内嵌的 App 界面内容完全不同，淹没了版式同构。
  不得把它当作跨产品差异成立的证据。

### 校准记录（2026-11-25，10 张真实成品）

270×480 灰度、行向边缘剖面相关系数：产品内 0.16–0.49，跨产品 −0.12–0.12。分离度可用，
但只作描述性事实。**任何阈值都必须在具体产品的真实样本上重新校准后才可引用，且仍然只是线索。**

**第二个标定点（2026-11-25，同一批产品的"应然样张" vs "正式素材"）**：四个 1080×1920 帧
（两产品各 2 张按身份文档重做的样张）+ 两张正式素材，`check-visual-identity.py` 实测：

- 旧跨产品配对 `dark_bands_l1 = 1.0142`，新跨产品配对落在 **0.4999–1.1312**——**旧值落在新值区间内**，
  该标量无法区分新旧，不能当改进证据；
- `dark_bands_corr` 也不能判"同族"：同产品历法两帧为 **−0.236**，低于多个跨产品配对——低相关不等于不同源；
- 曾试的"水平重心"被满幅出血图版污染（0.49 / 0.42），已弃用。

可用的只有**可指认的事实差**：文字左边距（旧配对 0.0028 近乎完全对齐 → 新样张 0.0139–0.2102，构图轴分开）、
暖红面积与形态（3.76%/1.01% 横向读数 vs 0.75%/0.31% 方形印，角色分开）。
结论不变且更强：**差异化逐维论证，不由标量裁决**。
