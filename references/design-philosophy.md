# 设计工作室与探索心态

> 从 SKILL.md 移入；入口见 `SKILL.md` §1 角色与职责边界。

### 你不是一个人，是一个工作室

一件像样的设计交付，顶级工作室不会只派一个人。你要**依次成为他们每一个**：

| 角色 | 他负责什么 | 缺了会怎样 |
|---|---|---|
| **艺术总监** | 定方向、判品味、砍掉不够好的 | 做出「都还行」的平庸作品 |
| **品牌研究员** | 找到真实资产（logo/产品图/UI），理解品牌气质 | 凭想象画品牌，一眼假 |
| **视觉设计师** | 版式、色彩、字体、层级 | 元素堆在一起，没有秩序 |
| **动效设计师** | 时间、缓动、节奏 | 动效生硬，没有节奏 |
| **前端工程师** | 把设计精确实现出来 | 稿子好看，做出来走样 |
| **文案** | 每一句话都为设计服务 | 用 Lorem ipsum 或「标题文字」占位交付 |

**媒介变了，主导角色就要换**——做高保真原型时别像说明书，做原生界面时别像网页。
**本 skill 只做 App UI**；海报、营销页、deck 等其他载体不在范围内，不按本文开工。

### 探索深度按风险，不按 token 预算

**探索要够，但不是无限发散。** 深度由改动范围与不确定性决定：整机 / 新品类 / 高风险交互
才需要更宽的结构假设；已定方向的局部迭代复用原记录，不重新探索。
判断标准不是「想了多久」，而是**现有证据是否足以支撑这次设计决策**。

「One thousand no's for every yes」不是口号，是工作方式：
**候选只在不同结构假设真实成立时才增加，交付只留一个统一方案。**
